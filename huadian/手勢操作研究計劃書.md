# 花店 App：全手勢操作與隱藏手勢 — 研究與設計計劃書

## 一、目標與願景

### 1.1 願景

將「唐風花鈿 AR 試妝」打造成**完全以手勢操作**、體驗流暢、且具**可探索性**的應用：  
使用者不需點擊滑鼠或觸控螢幕，僅憑手勢即可完成選妝、換背景、卸妝、以及**透過隱藏手勢解鎖額外功能**，形成「對鏡貼花黃」的沉浸感與遊戲化探索樂趣。

### 1.2 核心目標

| 目標 | 說明 |
|------|------|
| **全手勢操作** | 所有主要功能皆可透過手勢完成，無需實體點擊。 |
| **多手勢識別** | 支援多種明確、可區分的手勢（捏合、張開、滑動、握拳等）。 |
| **隱藏手勢** | 設計不寫在說明裡的「彩蛋手勢」，解鎖特殊效果或功能。 |
| **唐風一致性** | 手勢命名、解鎖內容與反饋皆與唐代／妝奩文化呼應。 |
| **可學習、可探索** | 新手能快速上手基本手勢；進階用戶能自然發現或猜測隱藏手勢。 |

## 二、現狀盤點

### 2.1 已有手勢

| 手勢 | 觸發條件（概念） | 功能 |
|------|------------------|------|
| **食指指向** | 食指指尖作為光標 | 懸停選取花鈿按鈕、卸妝按鈕 |
| **捏合** | 拇指與食指距離 < 閾值 | 確認點擊（佩戴花鈿 / 卸妝） |
| **張開手掌** | 拇指與食指距離 > 閾值，維持約 0.4s | 直接卸妝（不需對準按鈕） |

### 2.2 技術基礎

- **MediaPipe Hands**：單手 21 關鍵點，可取得指尖、指根、掌心等座標。
- **當前使用**：主要用食指尖 (8)、拇指尖 (4) 做光標與捏合判斷。
- **可擴展**：其餘關鍵點可用於更多手勢（握拳、比數字、滑動、雙手等）。

### 2.3 缺口

- 手勢種類少，尚未形成「手勢語言」。
- 無隱藏手勢與解鎖機制。
- 無手勢反饋系統（如輕震、音效、短動畫）。
- 無手勢說明／教學與探索引導。

## 三、手勢體系設計

### 3.1 分層架構

建議將手勢分為三層，便於實作與擴充：

```
┌─────────────────────────────────────────────────────────┐
│  第一層：基礎手勢（必備、有說明）                          │
│  選妝、確認、卸妝、光標移動                               │
├─────────────────────────────────────────────────────────┤
│  第二層：進階手勢（可選、有提示或教學）                    │
│  換背景、調整花鈿大小、切換鏡像、快捷卸妝等                │
├─────────────────────────────────────────────────────────┤
│  第三層：隱藏手勢（無說明、解鎖彩蛋）                      │
│  特殊濾鏡、限定花鈿、詩句／音效、彩蛋背景等                │
└─────────────────────────────────────────────────────────┘
```

### 3.2 第一層：基礎手勢（維持與微調）

| 手勢代號 | 名稱 | 識別要點 | 功能 |
|----------|------|----------|------|
| G_POINT | 食指指向 | 食指伸直，其餘可微彎 | 光標，懸停選取 |
| G_PINCH | 捏合 | 拇指尖與食指尖距離 < δ | 確認點擊（選花鈿 / 卸妝按鈕） |
| G_OPEN_PALM | 張開手掌 | 拇指與食指距離 > δ，維持 T ms | 一鍵卸妝 |

可微調：光標是否改為「中指／食指平均」以更穩；捏合／張開的 δ、T 可依實測再調。

### 3.3 第二層：進階手勢（建議新增）

| 手勢代號 | 名稱 | 識別要點 | 功能 |
|----------|------|----------|------|
| G_SWIPE_LEFT | 向左滑 | 食指軌跡在短時間內向左移動超過閾值 | 隨機換下一張背景 |
| G_SWIPE_RIGHT | 向右滑 | 同上，方向向右 | 隨機換上一張背景（或上一張花鈿） |
| G_FIST | 握拳 | 五指收攏，指尖靠近掌心 | 按住時：花鈿縮小；放開還原 |
| G_SPREAD | 五指張開再外擴 | 五指伸展且指間距離變大 | 按住時：花鈿放大 |
| G_TWO_FINGER_PINCH | 拇指+中指捏合 | 拇指與中指距離 < δ，食指可微伸 | 切換「鏡像 / 非鏡像」或鎖定當前背景 |
| G_PEACE | 比耶 | 食指與中指伸出且分開，其餘握拳 | 進入「拍照／截圖」模式（若實作） |

命名可再配合唐風文案，例如：滑動＝「翻頁／翻卷」、握拳＝「收扇」、張開＝「展扇」。

### 3.4 第三層：隱藏手勢與解鎖內容

**設計原則**：  
- 不寫在主要說明中，僅透過口耳相傳、成就提示或極簡線索讓用戶發現。  
- 解鎖內容與「唐風、花鈿、詩詞、妝奩」主題一致，避免與主流程衝突。

**候選隱藏手勢與解鎖內容**（可擇一或多項實作）：

| 隱藏手勢 | 識別要點 | 解鎖內容（示例） |
|----------|----------|------------------|
| **雙手合十** | 雙手皆偵測到，掌心相對、指尖朝上 | 播放短段古琴／箏音效；或畫面短暫「香霧繚繞」粒子效果 |
| **單手比「三」** | 拇指收，食指／中指／無名指伸直 | 解鎖「隱藏花鈿」一款（如額外設計的 9 號花鈿） |
| **拇指向上** | 拇指豎起，其餘握拳 | 隨機顯示一句唐詩（如「對鏡貼花黃」）浮於畫面 2 秒 |
| **搖一搖手** | 手腕快速左右擺動（透過關鍵點速度判斷） | 隨機切換到「彩蛋背景」一張（如 list 中標記為 hidden 的圖） |
| **食指豎唇前** | 食指伸直貼近嘴部區域（需粗略臉部相對位置） | 切換「靜音／有聲」或「害羞」濾鏡（若日後有濾鏡系統） |
| **雙手比心** | 雙手拇指與食指拼成心形（難度較高） | 解鎖「桃花緣」主題邊框或限定背景 1 張 |

隱藏手勢的**反饋**建議：  
- 輕微震動（若裝置支援）、短音效、畫面上一行小字（如「解鎖：xxx」）、或 0.5–1 秒的小動畫，避免打斷主流程。

## 四、技術實現要點

### 4.1 手勢識別流程

1. **輸入**：MediaPipe Hands 每幀輸出的 21 關鍵點（歸一化座標）。
2. **特徵**：  
   - 各指尖與拇指／掌心的距離。  
   - 相鄰指尖之間距離（張開/握拳）。  
   - 指尖軌跡與速度（滑動、搖晃）。  
   - 雙手的相對位置（雙手合十、比心）。
3. **狀態機**：  
   - 每種手勢對應一個小狀態機（idle → detecting → triggered → cooldown）。  
   - 避免同一手勢在同一秒內重複觸發；隱藏手勢可加較長 cooldown（如 5–10 秒）。
4. **優先級**：  
   - 基礎手勢（光標、捏合）優先，再判斷進階，最後判斷隱藏；或依「意圖」先判斷是否在按鈕上再決定是否觸發滑動／隱藏。

### 4.2 可複用模組建議

- **GestureDetector**：輸入 landmarks，輸出當前手勢代號 + 信心度。  
- **GestureRouter**：根據手勢代號與當前畫面狀態（是否戴妝、是否在選單）呼叫對應 handler。  
- **UnlockManager**：記錄哪些隱藏內容已解鎖、是否在 cooldown，並觸發反饋（音效／動畫／文案）。

### 4.3 難度與穩定性

- **較易**：握拳、張開、捏合、拇指上豎（僅看關鍵點距離）。  
- **中等**：滑動（軌跡+速度）、比耶／比三（指尖伸展狀態）。  
- **較難**：雙手合十、比心、食指豎唇前（需多關鍵點或與臉部相對位置）。  

建議先做「易→中」，隱藏手勢先選 1–2 個實現，再依用戶反饋擴充。

## 五、使用者體驗與發現性

### 5.1 說明與教學

- **首屏／幫助**：只說明第一層手勢（指向、捏合、張開手掌卸妝），搭配簡短文案與圖示。  
- **進階**：在「設置」或「？」中提供「進階手勢」列表（第二層），可選附短影片或 GIF。  
- **隱藏**：不提供列表；可在成就／統計中寫「已解鎖 x/5 彩蛋」等模糊提示，鼓勵探索。

### 5.2 反饋設計

- **即時**：光標樣式、按鈕 hover、捏合時光標變色（已有）。  
- **觸發**：手勢觸發時—輕微動畫（如按鈕閃一下）、可選短音效。  
- **隱藏解鎖**：專用音效 + 一行小字 + 可選輕震，讓用戶明確感到「解鎖了某樣東西」。

### 5.3 無障礙與容錯

- 手勢閾值（距離、時間）可做成可調（進階設置），或依裝置/環境做簡單自適應。  
- 保留「卸妝按鈕」的點擊與手勢雙通道，確保無法穩定做出手勢的用戶仍可操作。

## 六、實作階段建議

### 第一階段：基礎鞏固與一組進階（約 2–3 週）

- 重構手勢邏輯為「手勢識別 + 路由」，便於擴充。  
- 新增 **滑動換背景**（左/右滑），並在 UI 上給一句提示（如「試試左右滑動換背景」）。  
- 微調捏合/張開的閾值與防抖，減少誤觸與漏觸。

### 第二階段：進階手勢與反饋（約 2–3 週）

- 實作 **握拳/張開** 控制花鈿大小（或另一組進階手勢）。  
- 統一手勢觸發的反饋（動畫/音效）。  
- 撰寫簡短「進階手勢」說明並放入幫助/設置。

### 第三階段：隱藏手勢與解鎖（約 2–4 週）

- 選定 **2–3 個**隱藏手勢（建議先做：拇指上豎→唐詩、搖手→彩蛋背景、單手比三→隱藏花鈿）。  
- 實作 UnlockManager、解鎖內容與反饋。  
- 可選：簡單「成就」或「解鎖進度」文案，不寫出具體手勢，只寫「彩蛋 x/n」。

### 第四階段：打磨與測試（持續）

- 多裝置、多瀏覽器測試手勢穩定性。  
- 收集「哪些手勢常被誤觸／漏觸」，調整閾值或改為組合手勢。  
- 視情況增加 1–2 個隱藏手勢或解鎖內容。

## 七、研究問題（可作為實驗或論文方向）

1. **閾值**：捏合/張開的距離閾值、維持時間，在不同螢幕與鏡頭下最優區間為何？  
2. **發現率**：不寫明隱藏手勢時，用戶在 N 分鐘內自然發現幾個？是否需「第一次解鎖」後給一次線索？  
3. **滿意度**：全手勢 vs 手勢+按鈕並存，對沉浸感與易用性主觀評分的影響。  
4. **文化符號**：唐代相關手勢命名（如「展扇」「合十」）是否提升主題認同感或記憶度。
