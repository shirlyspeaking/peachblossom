# 花鈿背景音樂

## 如何聽到聲音

1. 將 **MP3**（或瀏覽器支援的音訊檔）放在本資料夾 `huadian/audio/`。
2. 編輯 **`list.json`**，在 `tracks` 陣列中寫入**實際檔名**，例如：

```json
"tracks": ["我的古風曲.mp3", "另一首.mp3"]
```

選擇任一花鈿後，會從 `tracks` 裡**隨機播放一首**。若 `tracks` 留空 `[]`，則改為從下方預設檔名中隨機（檔案必須存在且名稱一致）。

卸妝時音樂會停止。首次請先點「開啟鏡頭」（已內建音訊解鎖，較不易被瀏覽器擋自動播放）。
