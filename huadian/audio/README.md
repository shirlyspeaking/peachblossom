## 如何聽到聲音

1. 將 MP3 放在本資料夾，檔名與上表（及 `list.json`）一致。
2. **`list.json`** 的 `tracks` 必須列出資料夾內**實際存在**的檔名；新增或改名曲目時請同步修改 `tracks`。
3. 若將 `tracks` 設為 `[]`，程式會改從 `huadian.html` 裡各花鈿的 `bgMusic` 路徑合併去重後隨機（亦應與上表一致）。

卸妝時音樂會停止。請先點「開啟鏡頭」再選花鈿，以通過瀏覽器自動播放限制。

建議注意版權與授權。
