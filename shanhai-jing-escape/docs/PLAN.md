# 《山海經》主題密室逃脫設計綱要

## 與桃花源其他 App 的關係

- **本 App** 根目錄：`shanhai-jing-escape/`（與 `enjoyread/`、`class-monster/` 等 **平行**）。
- **勿** 將本遊戲的 HTML/CSS/JS 併入 `enjoyread/app.html` 或 EnjoyRead 套件。
- 桃花源入口網站 [`index.html`](../../index.html) 僅可放置 **連結** 至 `shanhai-jing-escape/index.html`。

## 設計原則（對齊「小五～成人」）

- **奇幻冒險基調**：避免血腥、驚嚇跳嚇；神怪以「造型誇張、色彩鮮明」呈現（可用皮影／剪紙／國潮插畫），輔以簡短人物卡說明出處與能力。
- **雙軌線索（同一謎題、兩種入口）**  
  - **兒童友善**：大量圖示、拼圖、配對、順序排列、身體動作、簡單算術（九尾、九頭等神話數字）。  
  - **成人加深**：諧音梗、古文短句、地誌式線索、邏輯推理或多步驟鏈。
- **協作角色分工**：每間密室暗藏「需要兩種視角」的資訊，鼓勵親子／師生組隊。
- **安全與場控**（線下版）：避免真火真水；聲音謎題音量可控。

## 世界觀與動線（建議 60～90 分鐘）

玩家扮演「巡視山川秩序的使者」，在 **崑崙／帝之下都** 式地圖上平息各方異象後開啟最終門。

完成任一扇區取得 **符印／碎片**；集齊後解 **終幕·山海合一**。

## 數位 prototype（本資料夾現況）

- **v0**：五方各一簡化謎題；通關取得五位數密碼片段（順序東→南→西→北→中）。數值以 [`scripts/game.js`](../scripts/game.js) 內 `SEAL_DIGITS`／`FINAL_CODE` 為準（目前 **91687**）；於「終幕」輸入結算。
- **待擴**：提示三級制、跳關代幣、`assets/` 配圖與音效、雙軌線索文案。

## 謎題類型（線下／進階）

- 配對：異獸圖 ↔ 山名／水系／方位  
- 順序：使者任務單排序  
- 空間：迷宫、倒影、鏡像、燈光角度  
- 協作：雙點同步按掣  

## 成功標準

- 玩家能說出「這關與這隻異獸有何關聯」。  
- 小五在提示下可完成全流程；成人仍有硬性推理步驟可挖深。  
- 不靠恐怖，靠好奇與解密成就感。
