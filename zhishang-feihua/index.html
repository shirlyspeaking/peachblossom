指上飛花

桃花源 · 中文輸入練習（詞語與段落）。本頁為靜態入口；完整功能由 Next.js 應用提供。

若已部署正式站，請編輯本目錄下 index.html，在 meta name="zhishang-feihua-app-url" 的 content 填入網址，訪客將自動前往。除錯時可在網址後加 ?stay=1 暫停跳轉。

本機開發：cd zhishang-feihua && npm run dev（預設埠 3210）。瀏覽器可執行 localStorage.setItem('zhishang_feihua_app_url','http://localhost:3210') 後重新整理，即可從本頁跳轉到本機。
