# 班級小怪獸點名 Demo

這是一個獨立的本機 Demo，先不併入「桃花源」也不部署。

## 功能

- **加分／扣分規則**：左側可編輯說明文字（僅供課堂參考，不自動計分），並會存進 `localStorage`；班級看板頂部可摺疊查看同一份規則摘要。
- **學生姓名管理**
  - **單筆加入**：輸入姓名後按「加入」或 Enter。
  - **批量加入**：於批量欄位貼上名單（換行、逗號、頓號皆可），按「批量加入」追加到現有班級。
  - **以清單覆蓋重建**：用批量欄位整班重建（會重置頭像種子與積分）。
  - **刪除**：卡片右上角移除單人；或使用「批次選取」勾選多位後「刪除選取」。
- 名單變動後，批量文字區會與目前班級名單同步，方便再複製編輯。
- 每位同學卡片可 **+1 / −1** 記錄課堂積分（與左側規則文字獨立）。
- 設定抽取人數、隨機點名動畫、「停！」後顯示中選者、瀏覽器語音朗讀。
- 班級名單暫存在 `localStorage`。

## 啟動

```bash
npm install
npm run dev
```

預設本機網址是 `http://localhost:5174/`。
